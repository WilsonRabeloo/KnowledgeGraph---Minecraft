# Knowledge Graph sobre o jogo Minecraft

Desenvolvimento de uma estrutura de dados **Knowledge Graph** desenvolvido em **Python** para a disciplina de **Algoritmos e Estruturas de Dados**.
O projeto ainda está **em desenvolvimento**, mas já conta com mais de 60 elemtos catalogados e alguma funcionalidades como adicionar e remover elementos ou relacionamentos.

---

## Sobre o projeto

O objetivo é desenvolver um Knowledge Graph capaz de catalogar os diversos itens inseridos no jogo Minecraft e os relacionamentos entre eles, por meio de uma interface visual compreensível e interagível.
